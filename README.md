# phamhscott.github.io

My personal website and blog — **[phamhscott.github.io](https://phamhscott.github.io/)**.

A portfolio of my projects and coursework, plus a place to write, built with
[Astro](https://astro.build).

## Run locally

```bash
npm install
npm run dev      # http://localhost:4321
```

`npm run build` outputs the production site to `dist/`.
